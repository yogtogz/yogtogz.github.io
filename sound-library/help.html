Sound Library of Babel

Complete documentation explaining the 61-character pitch block architecture, 84-level volume/velocity mapping, query syntax rules, text search behavior, and audio frequency equivalents.

1. Frame Structure & Input Syntax

Symbol / Feature Function & Behavior
61-Character Pitch Block The base unit of playback consisting of 61 channels per frame. Each block represents exactly 0.1 seconds of continuous sound. Consecutive blocks containing the same pitch and volume character sustain seamlessly across frames without dropping.
`|` (Pipe Separator) Used exclusively in the Search bar to chain custom frames together sequentially (e.g., entering 3:?|o:? creates a multi-frame sequence where each block plays consecutively for 0.1s).
`:` (Colons for Custom Volume) Used in the search bar to specify exact volumes per pitch using the pitch:vol syntax (e.g. 3:Z assigns volume `Z` to pitch `3`). If omitted, it automatically defaults to 100% volume (`?`).
`0` (Zero) Represents complete silence or an inactive pitch slot.

2. Search Text Mapping

How Search Translates Queries: The search bar relies purely on matching valid pitch characters found within your query text.

• Searching 3 will locate pitch slot 3 and assign it max volume, resulting in exactly 00?000....
• Searching one will locate pitch slots `o`, `n`, and `e` and assign them max volume simultaneously, generating a polyphonic chord sequence in a single frame.
• Searching 3:Z specifies you want volume Z applied explicitly to pitch 3.

3. Character-to-Frequency & Pitch Mapping

The library uses a 61-character pitch set spanning from 1 to Z:
123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ

The Mathematical Formula: Every position from index 0 to 60 maps to a unique sine wave frequency using the linear progression formula:

Frequency = 200 + ((Index / 60) * 3800) Hz
