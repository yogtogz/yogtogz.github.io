Sound Library of Babel

Welcome to the official documentation and reference guide. This document details how audio signals, frames, character indexes, and note frequencies are calculated and parsed.

1. Core Architecture & Frame Blocks

The library operates on a strict 62-character block architecture. Every individual frame of audio represents exactly 0.1 seconds of playback time.

Concept Syntax / Symbol Description
Frame Duration 0.1s per block Each 62-character string segment translates to a single 0.1-second audio frame slice.
Silence Selector 0 (at any index) Represents silence or an inactive audio channel. A block of pure zeros produces no sound.
Frame Separator | (Pipe) Used in search and input fields to chain sequential frames together (e.g., writing hello|world creates a multi-frame custom sequence).

2. Character Index & Frequency Mapping

The base alphabet consists of 62 characters (Base62):
0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ

How frequencies are determined: Index 0 is reserved for silence/padding (`0`). Indices 1 through 61 map linearly across a continuous frequency range from 200 Hz up to 4000 Hz using the formula:

Frequency = 200 + ((Index / 61) * 3800)
Character Position (Index) Approximate Frequency Behavior when active
Index 0 — Reserved for 0 (Silence / Inactive channel).
Indices 1 – 15 200 Hz – 1131 Hz Low-to-mid range tone channels. Triggered when valid alphanumeric characters occupy these exact slots.
Indices 16 – 45 1193 Hz – 3000 Hz Mid-to-high range melody channels. Polyphonic blending handles overlapping active slots smoothly.
Indices 46 – 61 3062 Hz – 4000 Hz High frequency chime and upper register channels.

3. Features & Data Management

Feature Details
Nicknamed Sounds Curated audio sequences mapped to human-readable names via nicknames.json. Displayed randomly on the home screen and compiled into a primary scrollable playlist.
Client-Side WAV Export Converts the active ID sequence into an uncompressed .wav file instantly in your browser using an OfflineAudioContext.
Local Storage & Sync User authentication, account themes, playlists, and settings are securely managed locally via IndexedDB.
