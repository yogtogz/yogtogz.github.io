1. Frame Structure & Input Syntax

Symbol / Feature Function & Behavior
62-Character Block The base unit of playback. Each block represents exactly **0.1 seconds** of continuous sound.
`|` (Pipe Separator) Used in search and custom inputs to chain frames together sequentially (e.g., entering hello|world creates a multi-frame sequence where each block plays consecutively for 0.1s).
`0` (Zero) Represents silence. Can occupy any index to turn off that specific pitch channel for that frame.

Frequency = 200 + ((Index / 61) * 3800) Hz
