Sound Library of Babel

Complete documentation explaining the 62-character block architecture, query syntax rules, audio frequency mapping, and character-to-note equivalents.

1. Frame Structure & Input Syntax

Symbol / Feature Function & Behavior
62-Character Block The base unit of playback. Each block represents exactly 0.1 seconds of continuous sound. If consecutive blocks contain the same character at the same index, the note will sustain seamlessly across frames without dropping in volume.
`|` (Pipe Separator) Used exclusively in the Search bar to chain custom frames together sequentially (e.g., entering hello|world creates a multi-frame sequence where each block plays consecutively for 0.1s).
`0` (Zero) Represents silence. Can occupy any index to turn off that specific pitch channel for that frame.

2. Character-to-Frequency & Note Mapping

The library uses the standard Base62 character set:
0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ

The Mathematical Formula: Except for index 0 (which is always silence), every position i from 1 to 61 maps to a unique sine wave frequency using the linear progression formula:

Frequency = 200 + ((Index / 61) * 3800) Hz

3. Application Features

Feature Description
Nicknamed Sounds Curated audio sequences mapped to human-readable titles in nicknames.json. Automatically compiled into a dedicated, scrollable playlist tab.
Client-Side WAV Export Uses an OfflineAudioContext to render the sequence directly in the browser and package it into an uncompressed .wav file. Applies exact sustain logic so continuous notes are generated perfectly.
