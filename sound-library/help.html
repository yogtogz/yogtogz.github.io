Sound Library of Babel

Complete documentation explaining the 84-character pitch block architecture (ranging from 1 through ?), 84-level volume/velocity mapping, query syntax rules, text search mapping fixes, and audio frequency equivalents.

1. Frame Structure & Input Syntax

Symbol / Feature Function & Behavior
84-Character Pitch Block The base unit of playback consisting of 84 channels per frame. Each block represents exactly 0.1 seconds of continuous sound. Consecutive blocks containing the same pitch and volume character sustain seamlessly across frames without dropping. Pitches use the full character set from 1 through ?.
`|` (Pipe Separator) Used exclusively in the Search bar to chain custom frames together sequentially (e.g., entering 3:?|00030... creates a multi-frame sequence where each block plays consecutively for 0.1s).
`:` (Colons for Custom Volume) Used in the search bar to specify exact volumes per pitch using the pitch:vol syntax (e.g. 3:? places maximum volume at pitch slot 3). If omitted in literal searches, search queries map input characters directly across slots.
`0` (Zero) Represents complete silence or an inactive pitch slot.

2. Text Search & Query Mapping (Bug Fixes)

Search Resolution Fix: Previously, searching text queries like one or three produced erroneous default outputs (such as 10000... or 30000...) due to improper index mapping.

Corrected Behavior: Text search queries now map input characters directly across the 84-character block slots using the full 84-character set. Explicit pitch selection (e.g., searching 3:?) correctly targets index 2 (slot 3) resulting in 00?00... instead of static misaligned fallbacks.

3. Character-to-Frequency & Pitch Mapping (1 through `?`)

The library uses an 84-level pitch character set spanning from 1 to ?:
123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ~!@#$%^&*()-_=+,<.>/?

The Mathematical Formula: Every position from index 0 to 83 maps to a unique sine wave frequency using the linear progression formula:

Frequency = 200 + ((Index / 83) * 3800) Hz
